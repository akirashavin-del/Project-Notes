Baseline optimizer

Nothing changes silently — every suggestion shows what changed, why, and what it risks.

Current
sum = 0 for i in range(len(arr)): sum += arr[i]
Suggested
total = sum(arr)
Why it's better — Uses the built-in reduction — same O(n) complexity, clearer intent, avoids shadowing the sum built-in. Semantically equivalent. No behavioral risk on this input type.

Explainable error

Errors are taught, not just reported.

raw error→ normalizer→ structured IR→ explainable AI
TypeError: expected int, got string — at compatibility_boundary(block_2, block_3)
The previous Python block produced a string, but the next block expects a number. This breaks the compatibility boundary between the two blocks. Convert the value to an integer before it crosses into block 3 — for example, int(value) right before the return.
